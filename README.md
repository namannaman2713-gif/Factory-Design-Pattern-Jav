## 📌 Introduction

This project demonstrates the implementation of the **Factory Design Pattern** using Java and Object-Oriented Programming concepts.

The application models movies, actors, theatres, screens, shows, and locations. It allows users to search for theatres based on movie names and actor names.

## 🎯 Objectives

- Understand the Factory Design Pattern.
- Implement object creation using a Factory class.
- Perform searches based on movie names.
- Perform searches based on actor names.
- Understand object-oriented programming concepts in Java.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Factory Design Pattern
- Visual Studio Code

## ⚙️ Features

1. Create movie and actor objects.
2. Maintain theatre and screen information.
3. Search theatres by movie name.
4. Search theatres by actor name.
5. Use Factory Design Pattern to select the appropriate search implementation.

## 🚀 How to Run the Project

### Prerequisites
- Java JDK installed.
- VS Code or any Java-supported IDE.

### Step 1: Open Terminal

Navigate to the project folder.

### Step 2: Compile the Java files

```bash
javac -d out *.java
```

### Step 3: Run the program

```bash
java -cp out com.university.java.semester5.designpatterns.factory.Main
```
